# 🚀 SummarizeAI - Free AI Text Summarizer & Translator

**Live Demo:** https://summarizeai.vercel.app

## ✨ Features

1. 📝 **Smart Summarizer** - AI-powered text summarization (Short/Medium/Detailed)
2. 🌐 **Instant Translator** - Translate to 50+ languages
3. 📧 **Email Analyzer** - Extract summaries, action items, priority & sentiment
4. 🛡️ **Fake Email Detector** - ML-powered phishing/spam detection

## 🛠️ Tech Stack

- **Frontend:** React + Vite + Tailwind CSS + Framer Motion
- **Backend:** Node.js + Express
- **AI:** Extractive summarization (no API keys needed)
- **Translation:** MyMemory Free API

## 🚀 Free Deployment Guide

### Frontend (Vercel - Free)

1. Go to [vercel.com](https://vercel.com)
2. Import your GitHub repository
3. Framework: Vite
4. Build Command: `npm run build`
5. Output Directory: `dist`
6. Click Deploy!

### Backend (Railway - Free)

1. Go to [railway.app](https://railway.app)
2. New Project → Deploy from GitHub repo
3. Root Directory: `server`
4. Start Command: `node index.js`
5. Add Environment Variable:
   - `NODE_ENV` = `production`
   - `PORT` = `3001`
6. Deploy!

### Alternative Backend (Render - Free)

1. Go to [render.com](https://render.com)
2. New Web Service
3. Build Command: `cd server && npm install`
4. Start Command: `cd server && node index.js`
5. Free tier available!
